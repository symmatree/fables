# Operating Modes

Cine - C mode (T mode)

Normal - N mode

Sport - S mode

# Operating Modes Description  

**Cine mode**: "C Mode" is displayed in the DJI Fly app. Cine mode is based on Normal mode with a limited flight speed and ascending and descending speed, making the aircraft more stable during shooting. This mode is most applicable when the aircraft has flown to the shooting position or when capturing starts. Cine mode changes how the drone maneuvers by slowing its rate of braking and rotation, creating more fluid movements and video captures.

**Normal mode**: "N Mode" is displayed in the DJI Fly app.  The aircraft utilizes GNSS, vision, and infrared sensing systems to locate itself, stabilize, and perform Intelligent Flight functions. In this mode, the flight speed is moderate, and various intelligent functions are available for usage. It is recommended that you use this mode for flight.

**Sport mode**: "S Mode" is displayed in the DJI Fly app. The aircraft utilizes GNSS and the Downward Vision System for positioning and hovering. The aircraft responses are optimized for agility and speed, making it more responsive to control stick movements. Note that obstacle sensing is disabled. Please fly with caution.

* For beginners, it is recommended to use N mode, this easy and safe mode for your first steps, and enjoy your flight and the various intelligent features.
